Triki Motion Controller — прокручиваемый интерфейс

Установка зависимостей:
  py -m pip install -r requirements.txt

Запуск:
  py TrikiMotionController.py

Интерфейс теперь прокручивается вертикально колесом мыши или полосой прокрутки.
Остальная логика контроллера и сохранение настроек оставлены без изменений.
